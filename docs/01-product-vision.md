# 01 — Product Vision

**StartupIQ — AI Startup Evaluator**: an AI-powered startup intelligence and decision-support platform.

## Goal
Help users understand a startup's:
- potential, readiness
- risks, strengths, weaknesses
- market/business position
- investment suitability, incubation suitability

## Eventual Outputs
Startup evaluation · explainable assessment · risk analysis · investor matching · incubator matching · evidence-backed insights · actionable recommendations.

## Final Product
A deployable web application that behaves like an intelligent startup analyst.

Core flow: see `02-user-journey.md`.

## Design Principle
- Product requirements: **stable**.
- Implementation (architecture, stack, database, models, agents, APIs, frontend, deployment): **open** until deliberately designed. See `09-open-decisions.md`.
