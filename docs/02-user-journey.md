# 02 — User Journey

## End-to-end Flow
User → startup information → startup profile → missing-information detection → targeted research → AI/ML analysis → risk/strength analysis → decision engine → explainable recommendation → investor matching → incubator matching → report/dashboard → optional continuous monitoring

## Input Principles
Do NOT assume a website, pitch deck or complete information. The system must work from basic information alone.

Possible input methods:
- conversational text
- structured questions
- website
- pitch deck / document
- optional voice input

## Intake Behaviour
1. Collect what the founder knows
2. Understand the information
3. Identify missing information
4. Ask only useful follow-up questions
5. Allow unknown answers
6. Research missing information only when appropriate (see `07-automation-and-agents.md`)
7. Build a structured startup profile

**Never invent unknown startup information.** Unknowns stay explicitly unknown.
