# 04 — Intelligence and AI

Use different techniques for different jobs. Do not use technology merely for buzzwords.

| Technique | Job |
|---|---|
| ML | Prediction from historical data |
| LLM / NLP | Understanding text, documents, startup descriptions, research |
| Rules | Deterministic constraints and business logic |
| Recommendation | Investor and incubator matching |
| RAG / knowledge retrieval | Evidence-backed information where useful |
| Agents | Specialized research/analysis workflows, only when they add genuine value |

## Assessment Output (multidimensional, not one label)
Overall startup assessment · success/outcome prediction · investment readiness · growth potential · risk · strengths · weaknesses · evidence · recommendation.

## Action Outcomes
INVEST / INCUBATE / REJECT. These are **not assumed to be the raw ML target**. The final decision may combine ML predictions, rules, startup profile, stakeholder requirements and evidence (see `06-explainability-and-decision-engine.md`).

Model choices are intentionally undecided (see `09-open-decisions.md`).
