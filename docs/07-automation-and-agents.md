# 07 — Automation and Agents

## Agents
Potential specialized agents: Startup Analyst · Market Research Agent · Financial/Risk Agent · Investor/Incubator Matching Agent · Orchestrator.

Agent count is **not fixed**. Choose the simplest architecture that provides real value; use agents only where they add genuine value.

## Market Research (targeted, cost-conscious)
- Reuse existing knowledge where possible
- Identify what is missing
- Perform only necessary research
- Prefer reliable sources
- Store useful evidence
- Avoid re-researching the same information

Supports: market analysis, competitors, industry trends, funding activity, relevant risks, regulatory/contextual information.

## Automation
Solve real problems only. Useful examples:
- Periodic startup monitoring
- Meaningful market/competitor changes
- Funding/news changes
- Re-evaluation when important information changes
- Notifications to users

Avoid unnecessary automation. Monitoring is optional in the final flow.
